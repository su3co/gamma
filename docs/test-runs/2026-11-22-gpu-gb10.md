# GPU runs on an NVIDIA GB10 (aarch64) — 2026-11-22

## scripts/gpu-test.sh

CUDA build of gamma (`scripts/build-cuda.sh`) on the GB10 machine, run through
the machine's job queue.

```text
gamma 0.1.0, lightsim 4ed0d651c9, linux-aarch64, f32
- cpu: aarch64 CPU
- cuda:0: NVIDIA GB10

## Fixture: GPU against CPU
- cuda:0: flux relative difference 4.4e-08 (ok)

## Throughput: perf-through.json   (the MMI example spec, full mesh, 4.6 M cells)
- cuda:0: cuda:0 (NVIDIA GB10, fused): 9000 steps in 17.3 s, 2.40 Gcells/s
```

## Remote run from a hub (vertical slice)

The MMI example (`examples/mmi-splitter`, full mesh) run from a gamma hub on
another machine with `gamma run through --host gb10 --device cuda:0`; the
host entry uses a `{host}` launcher (the fleet's job queue), so the spec was
staged over SSH, the worker queued, ran, streamed progress and was fetched.


# Remote run on an NVIDIA RTX PRO 6000 (x86_64) — 2026-11-22

The vertical slice: the MMI example (`examples/mmi-splitter`, full mesh, 4.6 M
cells) opened in gamma on a Mac (Apple M1 Pro, no CUDA), run with
`gamma run through --host rtx --device cuda:1` on a remote x86_64 machine with
two RTX PRO 6000 (Blackwell Max-Q) GPUs. The host entry uses a `{host}`
launcher: the machines' job queue, which held the job behind other users' GPU
jobs for about 88 minutes before it ran; gamma staged the spec over SSH,
the queue ran `gamma worker`, progress streamed back, and the results file was
fetched into `results/through/<run>/`.

The same spec on a GB10: 17.4 s, 2.39 Gcells/s, −3.04 dB per arm
([gpu-gb10](2026-11-22-gpu-gb10.md)). lightsim's own benchmarks give 18–27
Gcells/s on this GPU for larger boxes; this 4.6 M-cell problem is small for
it.

## Not run: scripts/gpu-test.sh on this GPU

A second job (the fixture compared with the CPU, and throughput) waited 50
minutes in the machine's queue behind other users' GPU jobs and gave up
(exit 75) without running; a second attempt with the per-GPU queue (`--gpus
any`, 60 minutes) ended the same way. The GPU-against-CPU comparison has been
run on the GB10 only.
